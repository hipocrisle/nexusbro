# Проверка выпуска 0.2.13

Выпуск опубликован 17.11.2026: тег `v0.2.13`, исходный код `c91458d589e87460bd6bf643bbdcada5064add2a`. [Релизный CI](https://github.com/hipocrisle/nexusbro/actions/runs/44078261347) завершился успешно на Windows и Linux. [Полная сборка кандидата](https://github.com/hipocrisle/nexusbro/actions/runs/44076205032) также прошла обе платформы.

Проверка Windows выполняет настоящие клики и клавиши по установленной программе. Она проверяет:

- перетаскивание границы встроенных DevTools, закрытие панели и возврат клавиатурного фокуса;
- русскую раскладку в странице CEF и оболочке, включая Ctrl+L/T/W/F;
- нативное меню адреса и копирование/вставку через системный clipboard;
- переключение звезды закладки, панель Ctrl+Shift+B и сохранение её настройки;
- перенос папок и закладок из Chromium JSON и Firefox SQLite при открытом WAL writer;
- загрузку настоящего файла, его имя и сохранение адреса исходной страницы;
- вторую копию EXE, два полноценных окна, переключение супер-вкладок в дополнительном окне без изменения главного и изоляцию профилей;
- обычный «+» из приватной вкладки, сохранность normal cookies, очистку приватного контекста;
- сохранение определения приватной супер-вкладки между запусками без cookies/localStorage прошлого сеанса, удаление временного каталога и завершение после последнего окна;
- прежние сценарии закрытия, перетаскивания вкладок, lazy restore, VLESS, отклонения нерабочего узла, восстановления туннеля, F5, рекламы и поиска.

Все 43 записи экранного прогона релизного установщика завершились успехом: [Windows](verification/0.2.13/windows.json). Первая попытка релизного CI упала на кратковременной блокировке файла снимка сессии (`PermissionError`) при чтении тестом. Повторный прогон неизменённого тега прошёл целиком. Для следующих прогонов в `dev` добавлено ограниченное ожидание чтения снимка (два секунды); постоянная ошибка по-прежнему приводит к падению теста. Код выпуска и проверки поведения не менялись.

[Результат Linux](verification/0.2.13/linux.json). Linux проходит проверку отсутствия публичного экспорта `sqlite3_*` и реальный Xvfb-прогон `tests/gui/linux_smoke.py`: загрузка документа в CEF, два окна, переключение супер-вкладок, локальное меню настроек и закрытие другой супер-вкладки без закрытия окон. Нативная библиотека SQLite импортера скрыта от динамического связывания CEF/WebKit/NSS: её экспорт приводил к SIGSEGV, который компиляция не обнаруживала.

Живой Google проверен из CEF через локальный прокси NexusBro на неизменённом Linux-бинарнике CI44069661186: текст документа переведён на русский, затем возвращён оригинал. [Результат](verification/0.2.13/live-translation.json). Проверка использует короткий искусственный текст, а не пользовательские страницы. Контракт тестового сервиса дополнительно проверяется воспроизводимой VLESS-фикстурой Windows; DOM-тест сохраняет поля ввода, код, изменения сайта и отбрасывает устаревшие ответы.

Frontend-тесты проверяют компактные одинаковые кнопки справа, цвета сети, меню, звезду, отсутствие signed URL в строке загрузки, очистку списка, мастер переноса, RU-команды, панель закладок и геометрию 10–20 вкладок. Тест меню адреса проверяет состав нативного меню и отсутствие вызова скрытия CEF; отдельный Chromium-прогон сохраняет проверки выделения слова, фрагмента и Ctrl+C/Ctrl+V.

Ограничения: доступность внешнего сервиса перевода зависит от выбранного выхода; текст отправляется Google. Мастер переносит закладки из стандартных каталогов поддержанных браузеров, включая папки; пароли, cookies и история не импортируются. Очистка списка загрузок оставляет файлы и активные загрузки. Явно сохранённые файлы и закладки остаются после приватного сеанса. Выдача Яндекса с сервера ограничена CAPTCHA: воспроизводимые проверки рекламы не гарантируют очистку всех вариантов на живых сайтах.

Проверены публичный `releases/latest/download/latest.json` (версия 0.2.13), отсутствие draft/prerelease, соответствие URL и подписей установщиков манифесту, размеры и SHA-256 GitHub Assets. Перед публикацией CI криптографически проверил Ed25519-подписи содержимого и trusted comment всех трёх пакетов. Сохранены [манифест](verification/0.2.13/latest.json), [проверка подписей](verification/0.2.13/signature-verification.json) и [результат публичной проверки](verification/0.2.13/public-release.json).
