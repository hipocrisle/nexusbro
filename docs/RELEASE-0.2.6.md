# 0.2.6: Windows-отрисовка и управление браузером

В 0.2.5 на Windows страницы загружались и меняли заголовки, но пользователь
видел чёрную область вместо контента. Диагностика подтверждала наличие
контейнера, а не отрисовку его дочерних браузеров. Записи о падении GPU в
`engine.log` относились к старому Chromium, поэтому не доказывали причину
текущего дефекта CEF. Воспроизведения на Windows в среде разработчика нет.

## Изменения отрисовки и диагностики

- Windows-процесс супер-вкладки использует `CefRunMessageLoop` вместо ручного
  опроса `CefDoMessageLoopWork` с `external_message_pump`. Команды обрабатывает
  периодическая CEF Task на том же UI-потоке, где создаются контейнер и браузеры.
  Дополнительная UI-нить не вводилась. Это один из рекомендованных режимов
  [CEF](https://github.com/chromiumembedded/cef/blob/master/include/cef_app.h).
- Явно выбран Alloy runtime для встроенных страниц. Собственные вкладки и
  навигацию предоставляет NexusBro.
- Показ Windows-контейнера поднимает его над соседним HWND оболочки WebView2
  через асинхронный SetWindowPos, не забирая фокус. Ранее порядок окон сохранялся.
- В диагностике есть версия приложения, размеры/видимость/классы HWND и дочерние
  окна. Текущий CEF пишет `cef-engine.log`; старый `engine.log` явно помечен.
  В `cef.log` появились этапы после инициализации, размер контейнера,
  ошибки загрузки и завершения renderer.
- Программный рендер остаётся исходным режимом; аппаратное ускорение можно
  включить в настройках. Изменение действует после перезапуска супер-вкладки.

Это исправления вероятных источников чёрного экрана, а не подтверждённое
исчезновение дефекта на Windows. Требуется повторная проверка пользователя:
открыть сайт, переключить супер-вкладку, свернуть/вернуть главное окно,
вызвать/закрыть настройки. При повторе нужна диагностика новой версии.

## Интерфейс

Новая пустая вкладка фокусирует адресную строку и выделяет `about:blank`.
CEF FocusHandler отклоняет запросы фокуса из навигации, чтобы поздняя загрузка
не отнимала клавиатуру; физический клик по странице разрешён. Первый фокус
адресной строки выделяет её содержимое.

Правый клик по обычной вкладке открывает меню: новая, обновить, дублировать,
закрепить/открепить, закрыть, закрыть другие, закрыть справа. Массовое закрытие
сохраняет закреплённые вкладки и передаётся движку одной командой, без заполнения
очереди множеством отдельных закрытий. Escape и клик снаружи закрывают меню.
Средний клик закрывает вкладку. На время меню CEF скрывается, затем возвращается.

Кнопка «« / »» сворачивает левую панель до 52 px и возвращает прежнюю ширину.
Разделитель перетягивается мышью в пределах 140–400 px (при перетягивании не
более 45% окна), также поддерживает стрелки клавиатуры. ResizeObserver передаёт
изменённую геометрию нативному CEF. Во время перетягивания CEF скрыт, чтобы
межпроцессные окна не перехватили мышь.

Кнопка ⚙ открывает настройки NexusBro: тёмная/светлая/системная тема оболочки,
поисковая система (DuckDuckGo/Google/Яндекс), страница новой вкладки, ширина
панели, автоматическая проверка обновлений и аппаратное ускорение страниц.
Для новой страницы разрешены HTTP(S) и `about:blank`. Ручная кнопка обновления
работает независимо от автопроверки. Адресная строка умеет искать текст.

Настройки лежат в `nastrojki.json` рядом со списком супер-вкладок. Запись через
временный файл и rename выполняется в spawn_blocking, сериализуется; интерфейс
сохраняет порядок изменений и сообщает ошибки. Ширина и свёрнутость панели
переживают перезапуск. Профили и обычные вкладки сохраняются прежним способом.

## Проверка

`npm run build`, Linux `cargo build`, Windows
`cargo check --target x86_64-pc-windows-gnu --features cef/dox` прошли.
Проверка Windows типов не является запуском Windows.

Расширен реальный сценарий `tests/gui/ordinary_tabs.py` с физическим вводом и
кликами xdotool, локальными страницами и изолированными данными. Помимо
прежней навигации, popup, cookies и сессий он проверяет:

- замену выделенного `about:blank` физическим вводом без Ctrl+A;
- действия контекстного меню и сохранность закреплённых при массовом закрытии;
- Escape из меню, изменение геометрии нативного CEF после сворачивания/drag;
- настройки, отказ сохранить недопустимый URL, восстановление после перезапуска;
- загрузку настроенной страницы новой вкладки;
- зелёный пиксель настоящей локальной страницы в области CEF (не только заголовок);
- отзывчивость при SIGSTOP движка и отсутствие движков после выхода.

Результаты, снимок и видео: `docs/verification/0.2.6/`.
Полный регрессионный бенч супер-вкладок также прошёл: повторное открытие
288–299 мс, правка 345 мс, закрытие/удаление 88–160 мс, переключение 92 мс.
Пять удалений при остановленном запуске, правка во время запуска и 20 повторных
переключений не оставили лишних движков. Максимальный интервал UI-таймера
74 мс в бенче и 23 мс в сценарии обычных вкладок. Два теста формата сессии прошли.
