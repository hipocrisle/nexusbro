# NexusBro 0.2.14

- Исправлено смешивание состояния истории, закладок и загрузок при переключении разделов.
- Обновлена стрелка меню новых вкладок.
- Добавлены цвета Super и заметный индикатор приватности в свёрнутой панели.
- Убрана белая полоса при изменении ширины DevTools, улучшено перетаскивание.
- Добавлены подсказки истории и дополнение URL в адресной строке.
- Добавлена очистка по Ctrl+Shift+Delete: история с периодом, завершённые загрузки, cookies и HTTP cache текущей Super. Файлы, закладки и localStorage сохраняются.
- Добавлен закреплённый автоперевод сайта в текущей вкладке с отменой; перевод ускорен пакетными запросами и устранением повторов.

Проверены Windows и Linux на настоящем CEF, включая два окна и приватные профили. Подробности: docs/REVIEW-0.2.14.md.
