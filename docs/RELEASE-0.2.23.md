# NexusBro 0.2.23

- Поиск по вкладкам и супервкладкам: Ctrl+Shift+A или меню браузера. Поиск по названию и адресу без запуска сайтов; переход в нужное окно и вкладку. Приватные страницы в общий поиск не входят.
- Устойчивое сохранение обычных сессий и восстановление дополнительных окон после сбоя. Восстановленные страницы загружаются по выбору; приватные сессии не восстанавливаются.
- Локальная зашифрованная история настроек супервкладок перед удалением и заменой из облака. Предпросмотр и явное восстановление с сохранением маршрута; без автоматической отправки в облако. Удалённые cookies и данные сайтов история настроек не возвращает.
- Понятные сетевые ошибки с выбранным путём и повтором: DNS, прокси/VPN, сертификат, TLS, тайм-аут. Автоматического перехода на прямое соединение нет.
- Диспетчер задач: Shift+Esc или меню. CPU и память процессов по супервкладкам; измерения только при открытом диспетчере. Общая память не выдаётся за память отдельной страницы.
- Перенос настроек, закладок и структуры супервкладок через файл с предпросмотром и обязательным выбором маршрутов. Cookies, VPN-секреты и приватные сессии не экспортируются; параметры и фрагменты адресов удаляются. Пароли — отдельным зашифрованным файлом с отдельным паролем копии.
- Стартовая проверка обновления показывает ход загрузки и ошибки после согласия; повторные нажатия в одном окне объединяются. Автоматическая проверка выполняется только главным окном. Исправлено наложение новых диалогов поверх открытых форм.

Обновление — встроенной кнопкой «Проверить обновления».
