# NexusBro 0.2.19 — проверка

Кандидат в работе, не опубликован. Публичная версия — 0.2.18.

Статус отдельной Super рассчитывается по отдельной квитанции аутентифицированного
обмена: хэш текущего переносимого определения должен совпасть с хэшем ответа
сервера. Существующая Local.meta не используется как ACK, поскольку snapshot
меняет её до сетевого обмена. Квитанции и признаки незавершённого/неудачного
обмена сохраняются в уже шифруемом локальном состоянии; серверный протокол
и production-сервис не изменяются.

Отключение только меняет выбор и группу интерфейса, без удаления локальных или
удалённых данных. Сохранённые закрытые Super отображаются локально и открываются
по явному нажатию, без автоматического запуска CEF. Приватные Super исключены.

Требуется полная native-приёмка с настоящим сервером: подтверждение, локальная
правка, ошибка обмена, перезапуск, восстановление, отключение сохранённой Super
без удаления данных. Обязательны Windows/Linux и проверка подписей публикации.
