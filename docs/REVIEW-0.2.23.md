# NexusBro 0.2.23 — единый выпуск

Все шесть функций и исправления стартового обновления опубликованы одним выпуском. Обновление доступно через встроенную кнопку ⟳ «Проверить обновления». Финальная нативная приёмка Windows/Linux, публикация и независимая проверка трёх публичных пакетов завершены успешно.

## Изменения

1. Ctrl+Shift+A: поиск по названиям, адресам и Super без запуска сайтов при чтении списка. Переход в нужное окно и вкладку проверяет ID, маршрут и поколения состояния, ждёт нативного подтверждения. Приватные страницы исключены.
2. Атомарные снимки сессии с проверенной резервной копией. Обычные дополнительные окна восстанавливаются после сбоя без загрузки всех страниц; приватные сессии исключены. Явно закрытое окно после рестарта не возвращается.
3. Зашифрованная локальная история настроек Super перед удалением и заменой из облака. Предпросмотр, явное восстановление и защита от устаревшего состояния. Удалённая Super возвращается сохранённой с прежним маршрутом, без запуска сайтов и автоматической отправки в облако. Cookies история не восстанавливает.
4. Настоящие ошибки Chromium с выбранным путём и кнопкой повтора. Автоматической смены маршрута нет. Сообщение и Retry расположены вне адресной формы; повтор не отправляет введённый адрес вторично.
5. Shift+Esc: CPU и память подтверждённых процессов экземпляра по Super и общим процессам. Неизвестное значение не выдаётся за ноль; общая память не приписывается отдельным страницам. Опрос раз в две секунды только при открытом видимом диспетчере.
6. Файловый перенос настроек, закладок и обычных Super: предпросмотр, обязательный выбор локальных маршрутов, новые ID без запуска страниц. Cookies, VPN-секреты, приватные сессии, параметры и фрагменты URL исключены. Пароли — отдельный файл с отдельным паролем, Argon2id и XChaCha20-Poly1305.

Стартовое согласие на обновление использует общий обработчик загрузки и ошибок. Проверка автоматически запускается только главным окном; ручная остаётся доступной в дополнительных. Исправлены наложение настроек поверх безопасности с сохранением несохранённой формы, повторные отложенные открытия диалогов и обрезанные столбцы диспетчера.

## Что принято до публикации

Приложение: `90af999e87080bec5994b11c77f82c37b1be7cb2`, пакеты [producer 45166201134](https://github.com/hipocrisle/nexusbro/actions/runs/45166201134). Исходники приложения после этой сборки не менялись; повторные прогоны проверяют пустой diff каталога `desktop`.

- [Windows 45169728107 — SUCCESS](https://github.com/hipocrisle/nexusbro/actions/runs/45169728107): physical GUI, маршруты/HTTPS, фоновая работа, AUTO с продолжающимся медиа, все шесть сценариев essentials.
- [Linux 45172164458 — SUCCESS](https://github.com/hipocrisle/nexusbro/actions/runs/45172164458): smoke, маршруты/HTTPS, настоящее хранилище/блокировка/синхронизация двух экземпляров; essentials 6/6, восстановление 6/6, история 5/5, backup 5/5.
- Essentials проверяет физические сочетания из оболочки и CEF, холодную вторую вкладку дополнительного окна с нулём HTTP-запросов к прежней активной странице, реальные OS-счётчики и исключение чужого процесса, настоящий сетевой сбой и физический Retry. Видимость Retry поверх CEF подтверждена пикселями экрана; таблица процессов помещается без горизонтальной прокрутки.
- Восстановление проверено настоящим SIGKILL/рестартом, штатным выходом и нативным закрытием окна. История проверена без сервера аккаунта, включая сохранение маршрута, stale guard, подтверждение удаления и отсутствие открытого текста в vault.
- Backup-интеграция на Linux использует настоящие GTK-диалоги, файлы и криптографию: выбор маршрутов, импорт в новые сохранённые Super, отдельный пароль, отказ при неверном пароле/повреждении ciphertext, расшифровка и импорт в vault. На обеих ОС выполнены девять Rust-тестов backup crypto/rollback/filesystem. Нативный Windows file-picker roundtrip этим отчётом отдельно не заявляется.

Producer в целом имеет статус FAILURE: его frontend-тест учитывал отложенное восстановление CEF после закрытия диалога как действие sync, а Windows-помощник ввода вызывал Linux `xdotool`. Это не переименовано в SUCCESS. Тестовые исправления проверены отдельно, неизменённые пакеты приняты указанными успешными прогонами. В помощнике backup-теста учтены выделение GTK имени без расширения и двойное Unicode-экранирование CSS-селекторов; строгие проверки файла, криптографии и маршрутов сохранены.
