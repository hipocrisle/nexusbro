# NexusBro 0.2.18 — приёмка

Статус: кандидат в работе; релиз ещё не опубликован.

Изменения: сайты видны во время скачивания обновления; QR-код настройки 2FA
формируется локально; облачная группа и пометки выбранных для синхронизации
супер-вкладок. Приватные Super исключены.

Метка облака обозначает включённую синхронизацию определения Super, а не
подтверждение актуальности каждой страницы или передачи cookies/истории.
Дата успешного обмена относится ко всему аккаунту. Сохранённые определения
с другого устройства открываются по нажатию, без автоматического запуска сайтов.

Локально: TypeScript/Vite PASS; 7 проверок updater PASS; Chromium security UI
с независимым декодированием QR, ручным ключом и отсутствием внешних запросов PASS.
Это fixture-проверки IPC, а не замена нативной приёмки.

Нативная приёмка должна проверить реальное экранное изображение QR, проверку
TOTP настоящим тестовым сервером, два устройства, облачные группы и перезапуск.
Проверка видимости updater исполняет production updater.ts с настоящим локальным
HTTP-потоком и реальными CEF-окнами; подтверждение и установщик ОС в этом сценарии
являются явными тестовыми адаптерами. Реальная установка этими адаптерами не доказана.

Production sync backend и системные сервисы не изменяются.

Исправление видимости сайтов действует после установки 0.2.18. Загрузку самой
версии 0.2.18 выполняет старый браузер, поэтому при этом переходе старое поведение
ещё возможно.
