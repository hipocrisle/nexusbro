# NexusBro 0.2.17 — исправления после проверки владельца

Статус: кандидат, ещё не опубликован. Публичное автообновление 0.2.16.

- Системные белые меню заменены HTML-меню в теме родительского окна. Они
  находятся поверх CEF, сайты остаются видимыми. Включены меню супервкладок,
  обычных вкладок, плюса, трёх полосок, адреса и страницы.
- Обычная регистрация и вход автоматически подключаются к отдельному сервису
  NexusBro, без ручного URL. Свой настроенный endpoint сохраняется; изменение
  доступно в дополнительных настройках. Ошибка подключения не означает успех.
- Пояснён сценарий паролей: создать локальное хранилище, ввести данные на сайте,
  подтвердить сохранение. Облачный аккаунт для локальных паролей не нужен.
- Если хранилище создано, запуск браузера требует мастер-пароль до показа сайтов.
  Ctrl+Shift+L блокирует весь браузер, хранилище и дополнительные окна; закрывает
  DevTools. Неправильный пароль не открывает данные и не меняет шифротекст.
- Средняя кнопка/Ctrl+клик и ПКМ → открыть ссылку создают вкладку в той же Super,
  сохраняя приватность. Фоновое открытие сохраняет исходную вкладку активной.

Проверки до выпуска: интерфейсные Chromium-фикстуры; реальные Windows/Linux
бинарники и CEF, включая цвета меню и видимый сайт, открытие ссылок, регистрацию
без URL на изолированном настоящем сервере, мастер-пароль при старте и блокировку
из сайтов/оболочки с несколькими окнами. Подготовленные сценарии не равны PASS.
Production sync в этом наборе не изменяется; используется проверенный отдельный
сервис. Автообновление будет объявлено готовым только после публикации и проверки
публичных пакетов/подписей. Не предлагать владельцу Actions ZIP.
