# NexusBro 0.2.25

- Исправлена смена пути открытой вкладки: обычные клики, формы поиска, canvas и загрузка страницы больше не блокируют явное переключение подключения.
- Переключение по-прежнему использует отдельный профиль выбранного пути. Входы не копируются, пути соседних вкладок не меняются, автоматического перехода на Direct нет.
- При настоящем отказе показана конкретная причина вместо общего «движок отклонил». Несохранённые данные, о которых предупреждает сама страница, и активный захват защищены.
- Описание выбора пути сокращено до одной строки. Автоматическая выгрузка памяти и защита фонового медиа не изменялись.

- Исправлена быстрая повторная блокировка Ctrl+Shift+L после разблокировки: команда больше не теряется, пока ожидается ответ предыдущей операции.

Обновление — встроенной кнопкой ⟳ «Проверить обновления».
