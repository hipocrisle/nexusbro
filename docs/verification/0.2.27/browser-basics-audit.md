# Базовые действия браузера: состояние перед нативной приёмкой

Аудит кода кандидата e6e853b. Наличие обработчика не означает прохождение проверки на экране.

| Действие | Код | Машинная проверка текущего кандидата |
|---|---|---|
| Ctrl+S и «Сохранить страницу…» | Новый нативный диалог и MHTML | Ожидает сборки и реального сохранения/открытия без сервера в чистом профиле |
| Ctrl+F, Ctrl+L, Ctrl+T/W/Shift+T, F5/Ctrl+R/Ctrl+F5 | Обработчики CEF и оболочки есть | Нужна приёмка итогового бинарника |
| Назад/вперёд кнопками | Обработчики есть | Нужна приёмка итогового бинарника |
| Загрузки: статус, открыть файл/папку | Реализовано | Предыдущий Linux-кандидат прошёл; Windows реально открыл Notepad и Explorer, затем не прошёл очистку теста. На новый код результат не переносится |
| Открыть ссылку в новой вкладке | Контекстное меню и CEF popup callbacks есть | Средняя кнопка требует отдельного реального подтверждения |
| Ctrl+P | Собственного обработчика нет | Пробел, не объявлять реализованным |
| Alt+Left/Right | Собственного обработчика нет | Пробел клавиатурной навигации; кнопки есть |

Для сохранения проверяются настоящие нажатия и нативный диалог, отмена, замена файла, ресурсы MHTML и открытие в новом профиле после остановки сервера. Unit-тесты не заменяют эти проверки. Публикация 0.2.27 по-прежнему требует лёгкого YouTube и остальных критериев.
