NexusBro 0.2.10

- Xray работает без отдельного чёрного окна Windows.
- При смене узла сначала проверяется HTTP(S)-соединение через него. Если проверка не прошла, прежнее подключение сохраняется. Если новый запуск не удался после проверки, программа возвращает прежние настройки и пытается восстановить соединение.
- При аварийном завершении Xray программа автоматически восстанавливает туннель и активную страницу. Повторный сбой в течение минуты показывается сообщением без бесконечных перезапусков.
- В общих настройках подписки показаны список узлов, доступность и задержка запроса через каждый узел. Общий выбор узла убран; нужный узел выбирается в настройках супер-вкладки.
- Ошибка применения настроек остаётся в открытом диалоге: можно выбрать другой узел или отменить правку.

Измерение задержки использует проверочные адреса Google/Cloudflare. Недоступность обоих адресов может привести к отказу проверки даже при работоспособности других сайтов. Проверка не отправляет содержимое страниц.
