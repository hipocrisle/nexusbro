закрытия всего NexusBro при закрытии обычной вкладки проверена на Windows.

Сборка и результаты относятся к коду приложения 0.2.8; последующие изменения
этого отчёта и ожиданий перед снимками экрана не меняют приложение.

## Устойчивость супер-вкладок

Полный стресс-сценарий прежнего отчёта перенесён в `tests/gui/supertabs_stress.py`.
Открытие сохранённой: 289–300 мс; правка работающей: 317 мс; закрытие:
88–166 мс. Пять остановленных при запуске движков удалены за 90–94 мс,
PID и профиль прибраны. Правка при SIGSTOP убирает старый PID. Двадцать
одновременных переключений не создают лишних движков; поздний запуск не
перекрывает выбранную вкладку. Удаление отсутствующего профиля: 89 мс.
Максимальный интервал UI-таймера в стрессе: 502 мс, без зависания >1 секунды.
После штатного выхода GUI-прогона живых движков нет.

## Повторение

После сборки запустить отдельный Xvfb (например, `:96`, 1280×900):

```sh
python3 tests/gui/ordinary_tabs.py --display :96 --out result.json
python3 tests/gui/vpn_subscription.py --display :96 --format xray --out vpn-json.json
python3 tests/gui/vpn_subscription.py --display :96 --format links --out vpn-links.json
```

Для `supertabs_stress.py` отдельно запустить приложение с изолированными
`XDG_DATA_HOME`, `XDG_CONFIG_HOME`, `XDG_CACHE_HOME`, `DISPLAY=:96`,
`WEBKIT_INSPECTOR_HTTP_SERVER=127.0.0.1:9223`. Затем:

```sh
python3 tests/gui/supertabs_stress.py --display :96 --data /absolute/path/to/test-data --stress --out stress.json
```

Windows проверяется `tests/gui/windows_physical.py` в workflow `build.yml`.
Никаких пользовательских подписок, профилей или внешних тестовых страниц не нужно.

## Существенные детали

CEF по умолчанию может отправить WM_CLOSE верхнему родителю встроенного окна.
Обработчик закрытия теперь возвращает true и ставит отложенную задачу уничтожения
только HWND обычной вкладки с проверкой PID/потока/родителя. Контейнер и главное
окно при этом не закрываются. Основание: [CEF LifeSpanHandler](https://cef-builds.spotifycdn.com/docs/154.0/classCefLifeSpanHandler.html).

DevTools требуют Chrome style даже при Alloy-странице:
[решение CEF о runtime styles](https://github.com/chromiumembedded/cef/issues/3685).
HTML5 drag-and-drop на Windows требует отключения собственного drag handler
WebView2 в Tauri; это сделано `dragDropEnabled: false`:
[официальная конфигурация Tauri](https://v2.tauri.app/reference/config/#windowconfig).

Назначения сервисов в отчёте защиты — описания сервисов, не анализ содержимого
конкретного запроса. Например, [Google tag](https://support.google.com/analytics/answer/17231523),
[Яндекс Метрика](https://yandex.ru/support/metrica/ru/general/counter-general),
[Sentry Error Monitoring](https://sentry.io/product/error-monitoring/).
Ограничения доменного блокировщика описаны в [заметках выпуска](RELEASE-0.2.8.md).
