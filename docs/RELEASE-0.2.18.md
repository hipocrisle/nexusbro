# NexusBro 0.2.18

- Сайты остаются видимыми во время скачивания обновления. Ошибка установки или перезапуска возвращает страницы на экран.
- Настройка двухфакторной аутентификации: локальный QR-код для приложения-аутентификатора, пошаговые подсказки и ручной ввод ключа при необходимости.
- Облачные пометки супер-вкладок с включённой синхронизацией. Приватные супер-вкладки исключены; отметка выбора данных не выдаётся за подтверждение успешного обмена.

Обновление доступно через штатную проверку обновлений браузера после публикации релиза.
