# NexusBro 0.2.17

- Меню снова оформлены в теме NexusBro: у плюса, трёх полосок, супервкладок,
  обычных вкладок, адреса и на странице. Открытый сайт остаётся видимым.
- Подсказки адреса используют тему NexusBro и сохраняют клавиатурный фокус;
  системный белый список больше не перехватывает горячие клавиши.
- Регистрация и вход используют отдельный сервис NexusBro автоматически.
  Вводить адрес сервера не требуется; собственный сервер — дополнительная настройка.
- Средняя кнопка/Ctrl+клик и контекстное меню открывают ссылку в новой вкладке
  той же супервкладки с сохранением приватности. Фоновое открытие сохраняет
  исходную вкладку активной.
- После создания хранилища при запуске браузера нужен мастер-пароль.
  Ctrl+Shift+L блокирует браузер и хранилище во всех его окнах; сайты и DevTools
  скрыты до разблокировки. Текущие вкладки сохраняются.
- Добавлены пояснения сохранения паролей: создайте локальное хранилище, войдите
  на сайт и подтвердите предложение сохранить логин/пароль. Облачный аккаунт
  для локального сохранения не нужен. Приватные вкладки исключены.

Обновление — через штатное автообновление. Мастер-пароль хранилища и пароль
аккаунта NexusBro — разные пароли. Существующий мастер-пароль менять не нужно.
