# NexusBro 0.2.7 — Windows: область страницы и проверка изображения

- Область CEF исключена из HWND оболочки WebView2. Полная область оболочки
  возвращается на время диалогов и после закрытия/смерти движка.
- Размер выреза следует за изменением окна и ширины/сворачиванием панели.
- Диагностика снимается до скрытия страницы, показывает дерево главного окна,
  PID/потоки/родителей, Z-order, расширенные стили и регионы HWND.
- В настройках супер-вкладки можно выбрать конкретный узел VPN-подписки;
  исчезнувший узел даёт ошибку вместо подключения через другой.

Физический Windows runtime-тест на первом кандидате подтвердил реальный экранный
цвет CEF после запуска, диалога и resize; выявил полосу после сворачивания панели.
Соответствующее обновление геометрии добавлено в текущий исходник.
Проверка полного сценария итогового пакета и публикация ещё ожидаются.

Отрисовка на пользовательской Windows-машине не подтверждена; 0.2.6 пользователь
проверил с отрицательным результатом. Успех на Windows CI не заменяет проверку
конкретной машины. Детали: WINDOWS-RENDER-REGIONS.md.
