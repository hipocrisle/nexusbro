# Приёмка 0.2.9

Код приложения `50557a9` проверен на GitHub Actions:
[полная сборка и native Windows](https://github.com/hipocrisle/nexusbro/actions/runs/43837683362)
и [быстрая проверка интерфейса](https://github.com/hipocrisle/nexusbro/actions/runs/43837679074).
Оба прогона завершились success. Rust/CEF на сервере разработки не собирались.

## Подписки и код 23

Причина воспроизведена настоящим Xray: конфигурация с `geoip:private` завершалась
с кодом 23 и сообщением `failed to open file: geoip.dat`. В 0.2.8 из архива Xray
извлекался только бинарник. В 0.2.9 упакованы также GeoIP/GeoSite; launcher передаёт
расположение баз через `XRAY_LOCATION_ASSET`.

`tests/xray_assets.py` запускает реальный `xray run -test` на конфигурации с
GeoIP, GeoSite, VLESS-выходом, leastPing и burstObservatory. Проверка выполнена
на обеих платформах и отдельно на Xray с базами из распакованного NSIS-пакета.
Это проверка конфигурации без сетевых соединений. Пользовательские URL, UUID,
подписки и узлы не копировались в тесты или репозиторий.

## Списки и узлы

`tests/frontend_controls.py` проверяет собранный интерфейс реальными mouse clicks
в Chrome, с локальной фикстурой Tauri IPC. Проверены:

- выбор Arial и компактной плотности;
- загрузка полного списка узлов и выбор второго;
- сохранение узла по умолчанию и подстановка в форму супер-вкладки;
- выбор другого узла и переключение на прямое соединение;
- отсутствие native select, геометрия popup внутри viewport;
- отсутствие пустого расстояния между последней вкладкой и плюсом;
- понятное состояние спящей страницы.

`tests/gui/windows_physical.py` дополнительно проверяет реальный WebView2 в
установочном пакете: UI Automation находит элементы, затем `click_input()`
нажимает их физической мышью. Выбор Arial сохраняется в `nastrojki.json`, после
чего системный шрифт выбирается обратно. Popup рисуется в DOM через portal,
не обрезается scroll-контейнером настроек и открывается вверх/вниз по месту.

## Восстановление без загрузки страниц

Native Windows-прогон:

1. Созданы три обычные вкладки и сохранена сессия.
2. Приложение завершено; в тестовой сессии заданы три ранее не посещавшихся URL
   локального HTTP-сервера. Настройка «открывать пустой» выключена.
3. Приложение перезапущено. Все три записи имеют `otlozhena=true`, HTTP-запросов
   к этим страницам нет; показана кнопка «Загрузить вкладку».
4. Физический клик по первой вкладке создаёт только её браузер. Сервер видит
   запрос к первой странице, запросов ко второй и третьей нет.
5. Реальные экранные RGB после загрузки совпали с фоном тестовой страницы во
   всех трёх контрольных точках: `(24,85,65)`. Кнопка новой вкладки нажата мышью.

В том же прогоне повторно пройдены средняя кнопка/крестик/контекстное закрытие/
Ctrl+W/последняя→blank, source-tab, F12, drag обычных вкладок, отрисовка после
диалога, resize и collapse боковой панели.

## Повторение

Полная сборка и все проверки:

```sh
gh workflow run build.yml --ref dev
```

Быстрый frontend-прогон без компиляции Rust:

```sh
gh workflow run build.yml --ref dev -f frontend_only=true
```

Архивы и подписи для пользователей выпускаются обычным тегом `v0.2.9`.
Старые Linux GUI-сценарии адаптированы к DOM combobox и явному выбору
восстановленных вкладок; повторно на DE-1 не запускались.
