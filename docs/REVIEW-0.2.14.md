Автоперевод действует в памяти вкладки на одном origin; переход на другой сайт не включает отправку его текста автоматически. «Показать оригинал и выключить» отменяет перевод и его закрепление. Запросы используют выход Super; приватный текст не кэшируется на диск. Длительность полной большой статьи Wikipedia не измерена: время короткой пробы нельзя переносить на неё.

Период очистки относится к общей истории посещений. Завершённые загрузки очищаются из списка за всё время; скачанные файлы и активные задания остаются. Cookies и HTTP cache очищаются за всё время только в текущей Super, включая её открытые окна. Это не полная очистка localStorage; диалог прямо сообщает ограничение. Закладки не удаляются.

Локально прошли `npm run build` и последовательные Chromium-проверки frontend_controls, browser_ui_0213, address_selection, library_state_0214, super_colors_0214, translation_dom, address_autocomplete_0214. Tauri IPC в этих проверках заменён фикстурой; native подтверждения приведены отдельно после CI. Rustfmt использован только для проверки разбора, не как замена компиляции.

Другие переводчики исследованы без подключения: [DeepL API](https://developers.deepl.com/docs/getting-started/quickstart) требует отдельного ключа и плана; [Firefox](https://support.mozilla.org/en-US/kb/website-translation) переводит на устройстве с языковыми моделями, но это отдельная интеграция для CEF; [LibreTranslate/Argos](https://docs.libretranslate.com/) можно разместить самостоятельно. Сравнение качества и скорости немецкий→русский не проводилось, превосходство какого-либо варианта не заявляется. В текущем наборе сервис не меняется.

Промежуточный Linux CI 44097105042 на 271adb5 завершился успешно: настоящий CEF подтвердил persistent color без остановки браузера, наблюдаемое удаление cookies, callback завершения cache clear, историю/suggestions и два окна с независимым переключением Super. Результат: verification/0.2.14/linux-initial.json. Windows этого прогона ещё выполняется. После него внесены дополнение URL, guard отменённого snapshot, сохранение перевода при #anchor и очистка pending waiter при отмене команды; окончательная приёмка должна относиться к новой ревизии, а не к первому SHA.
