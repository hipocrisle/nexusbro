# NexusBro 0.2.20 — нативная приёмка

Опубликована 20.11.2026 в 09:23:47 UTC. Публичный updater и подписи всех трёх пакетов проверены. Источник подписанных пакетов: `3b529f5d0c93edcd22c17a8e09e7f4b71fcc41a9`, сборка [44705290800](https://github.com/hipocrisle/nexusbro/actions/runs/44705290800).

Автоматическая экономия включена по умолчанию через 30 минут; варианты 15/30/60/120/240 минут применяются без перезапуска. Исключение отдельной вкладки — через ПКМ. Активные, закреплённые, приватные, страницы с вводом, медиа, WebAudio/WebRTC, загрузками и DevTools остаются живыми. Неизвестное состояние запрещает выгрузку. Автоматика также сохраняет живыми страницы с внутренней историей и sessionStorage.

Это выгрузка отдельных безопасных страниц с последующей перезагрузкой, без объединения движков и остановки всей супервкладки. Ручная команда предупреждает о потере внутреннего состояния. Строка становится спящей только после настоящего OnBeforeClose; восстановление создаёт новый Browser после закрытия старого.

Компактное облако использует подтверждение сервером текущих данных каждой супервкладки. Дата находится в подсказке; отключённые записи переходят в «На устройстве» без удаления. Нативная Linux-приёмка включает ошибку связи, рестарт и восстановление зелёного статуса.
