# NexusBro 0.2.20

- Автоматическая экономия памяти неактивных вкладок: по умолчанию через 30 минут, интервал выбирается в настройках и применяется без перезапуска.
- Вкладки с медиа, WebAudio/WebRTC, несохранённым вводом, загрузками и DevTools, а также приватные и закреплённые вкладки защищены от автоматической выгрузки. Отдельную вкладку можно исключить через ПКМ → «Не выгружать автоматически».
- Ручная выгрузка через ПКМ предупреждает о перезагрузке страницы. Автоматическая выгрузка сохраняет строку вкладки; при открытии восстанавливаются адрес, cookie, localStorage и прокрутка.
- Компактное облако вместо длинной подписи с датой: зелёное — текущие данные подтверждены сервером, красное — ошибка, серое — обмен отключён. Дата находится в подсказке. Отключённые супервкладки переходят в «На устройстве» без удаления.
- Исправлены потеря подтверждений между паролями, переводом и управлением памятью, лишняя служебная страница в истории и заблокированная повторная попытка после защитного отказа.

Обновление доступно через встроенную проверку обновлений после публикации выпуска.
