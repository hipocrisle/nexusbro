# NexusBro 0.2.21

- Синхронизацию выбранных данных можно запустить нажатием на облако в панели или рядом с супервкладкой, без открытия настроек. Пока операция выполняется, повторный запуск заблокирован; ошибка не выдаётся за успешную синхронизацию.
- Значков облака больше нет у локальных и приватных супервкладок — и в развёрнутой, и в свёрнутой панели.
- Из ПКМ обычной вкладки убраны ручная выгрузка памяти, её диалог и ручное исключение из автоматической выгрузки. Экономия работает автоматически; старые скрытые исключения больше её не блокируют.
- Медиа, несохранённый ввод и выполняющиеся загрузки защищаются автоматически, без действий владельца.
