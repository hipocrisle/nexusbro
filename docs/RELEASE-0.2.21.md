# NexusBro 0.2.21

- Для каждой обычной вкладки можно выбрать путь супервкладки, прямое соединение или сохранённый VPN. Выбор сохраняется после перезапуска. Одинаковые пути внутри супервкладки разделяют профиль; у разных путей отдельные cookies и входы. Авторизация между путями не копируется, недоступный путь не заменяется Direct.
- Синхронизация выбранных данных запускается нажатием на облачко, без открытия настроек. Зелёный статус появляется после подтверждения сервера. У локальных и приватных супервкладок значков облака нет, включая свёрнутую панель.
- Убраны ручные команды выгрузки памяти и исключения для отдельных вкладок. Автоматическая экономия включена по умолчанию, 30 минут. Медиа, несохранённый ввод и выполняющиеся загрузки защищаются автоматически. Безопасная выгруженная страница восстанавливается по нажатию.
- Исправлены сохранение профилей отдельных путей и завершение индикатора загрузки после сетевой ошибки. Прежний профиль супервкладки остаётся на месте.

Проверены настоящие Windows/Linux сценарии маршрутов и изоляции, HTTPS, работа при недоступном подключении, синхронизация двух устройств, автовыгрузка и медиачасы. Парный Windows-тест использовал 8 супервкладок, 1000 сохранённых и 24 открытые страницы.

Обновление устанавливается обычной встроенной кнопкой «Проверить обновления».
