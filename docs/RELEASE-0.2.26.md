# NexusBro 0.2.26

- Добавлен сценарий «Забыли мастер-пароль?» на экране блокировки, по образцу NexuSSH.
- Сброс сохраняет прежнее хранилище зашифрованной копией и создаёт пустое под новым мастер-паролем. Операция требует явного подтверждения.
- Копию можно выбрать по дате и восстановить прежним мастер-паролем. Текущее хранилище также сохраняется в зашифрованную копию.
- Неверный пароль или ошибка сохранения не снимают блокировку. Сайты, обычные настройки и вкладки не удаляются; облачные данные автоматически не стираются.

Обновление — встроенной кнопкой ⟳ «Проверить обновления».
