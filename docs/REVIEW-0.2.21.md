# NexusBro 0.2.21 — кандидат, ещё не опубликован

Публичная версия пока 0.2.20. Кандидат объединяет исправления облака и полностью автоматический UX памяти по отзыву владельца.

Облако — настоящая отдельная кнопка рядом с кнопкой супервкладки, без вложенных button. Используется прежний security_sync run с сохранённым выбором; никакого автоматического включения локальных записей. Состояние зелёное только после свежего native ACK. Click/Enter/Space, busy/dedupe, ошибки/конфликты и retry, отсутствие запуска сохранённых движков/переключения вкладки/скрытия CEF проверяются Chromium-фикстурой и нативной приёмкой с настоящим изолированным sync-server.

Ручные memory-пункты и диалог удалены. Автоматическая политика включена по умолчанию, 30 минут; медиа/ввод/загрузки и другие unsafe/unknown страницы не выгружаются. Никаких ручных keep/unload не требуется. Старый memory_keep не создаёт невидимого вечного исключения. Восстановленные невыбранные страницы остаются lazy.

Новый нативный Windows-gate не отправляет manual unload/keep и не включает автоматическую экономию вручную. Он проверяет default ON, lazy страницы без запросов, отсутствие manual memory меню, сохранение активной страницы сверх idle-интервала, настоящий Win32 scroll, 15 секунд реального minimize, автоматический close в свёрнутом состоянии, пять private commit сэмплов и ≥64 МиБ освобождения, прежние cookie/localStorage/scroll. HTML playing/paused и WebAudio часы, локальный RTC, черновик/загрузки/DevTools/private/pinned защищены автоматически. 120-секундный WAV исключает ложное совпадение из-за modulo короткого loop. Короткий таймер 8 секунд включается только для изолированного TEST_DATA; нормальный UI сохраняет 30 минут.

Локальные TS/Vite и bundled Chromium cloud fixture прошли; нативные результаты кандидата ещё ожидаются. Изменений production services/env/Telegram/proxy нет. Сборки и CEF только на GitHub.

Индивидуальный приоритет пути обычной вкладки — отдельная незавершённая задача, не функция этого выпуска. Существующий успешный Linux probe переиспользуется, Windows-проверка запущена отдельно.
