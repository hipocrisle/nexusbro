# NexusBro 0.2.9

Исправлены запуск VPN-подписок и выбор параметров на Windows. Восстановленные
страницы больше не загружаются до выбора вкладки.

- В установщик входят базы `geoip.dat` и `geosite.dat` для правил маршрутизации
  Xray. Их отсутствие в 0.2.8 приводило к завершению Xray с кодом 23. Конфигурация
  с GeoIP, GeoSite и балансировщиком теперь проверяется реальным Xray при сборке
  и после извлечения Windows-установщика. Граф выходов подписки сохраняется.
- Выпадающие списки шрифтов, масштаба, плотности и узлов работают внутри
  интерфейса, без нативного popup WebView2. Есть поиск и управление клавишами;
  список открывается в доступную сторону и не обрезается краем диалога.
- В разделе «Сеть и VPN» у сохранённой подписки можно раскрыть «Узлы подписки»,
  загрузить все узлы и выбрать узел по умолчанию для новых супер-вкладок.
  Выбор сохраняется кнопкой «Сохранить». В настройках супер-вкладки список
  загружается автоматически после выбора подключения или ввода адреса подписки.
- После перезапуска восстанавливается список вкладок, а не загрузка всех страниц.
  Спящие страницы сохраняют адреса, названия, порядок, закрепление и значки.
  Для открытия нажмите вкладку или «Загрузить вкладку». Это касается и страницы,
  которая была активна перед выходом. Новые вкладки продолжают открываться сразу.
- Плюс новой обычной вкладки расположен сразу после полосы вкладок. При большом
  числе вкладок он остаётся доступен рядом с прокручиваемой полосой.
- Ошибки запуска Xray теперь классифицируются; сырые сообщения с параметрами
  подключения не попадают в пользовательскую ошибку. Подробный локальный журнал
  остаётся в профиле.

В 0.2.8 проверялся VLESS с простым тестовым маршрутом без геобаз. Этот сценарий
не обнаружил ошибку упаковки GeoIP. В 0.2.9 проверка установщика включает
конфигурацию с геоправилами, а проверка списков использует реальные клики мышью.

Сборки и автоматические проверки выполняются в GitHub Actions. Каталоги Cargo
на сервере разработки не создаются.
