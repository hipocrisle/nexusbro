# NexusBro 0.2.22

Убраны повторяющиеся облачки у отдельных супервкладок в группе «Облако»: открытых, сохранённых и в свёрнутой панели. Убран и лишний отступ под эти значки.

Один общий значок в заголовке группы показывает статус синхронизации и запускает её по клику. Цвета успешной синхронизации, ошибки и ожидания сохранены.

Обновление — через встроенную кнопку «Проверить обновления».
