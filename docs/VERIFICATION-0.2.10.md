# Проверка 0.2.10

Причина отдельного окна Windows найдена в `brauzer.rs::zapustit_prosto`: консольный Xray запускался без CREATE_NO_WINDOW. При закрытии его окна погибал VPN, а прежний watchdog проверял только CEF. Исправлены оба участка.

Проверка нового узла выполняет HTTP(S)-запрос через временную цепочку HTTP-proxy → SOCKS5 → Xray → выбранный узел. Прямого обхода нет. Временные процессы и конфигурация удаляются RAII-охранниками, включая отмену на этапе ожидания порта. Одновременно допускается не более двух проверок.

`tests/frontend_controls.py` проверяет список с доступностью/задержкой без выбора общего узла, независимый выбор в супер-вкладке, шрифты, popup и спящие вкладки. IPC здесь заменён фикстурой.

`tests/gui/windows_physical.py` дополнен настоящим локальным VLESS-сервером на Xray из установщика. Домен vpn-fixture.test не существует в публичном DNS; только маршрут VLESS-сервера перенаправляет его на HTTP-фикстуру. Проверяются физический выбор узла, загрузка через VPN, отсутствие новой видимой консоли, сохранение старого подключения при выборе недоступного узла и автоматическое восстановление после принудительной остановки только дочернего Xray тестового приложения.

Сохраняются проверки настоящего CEF: закрытие вкладок, F12, исходник, drag, отрисовка и отсутствие запросов восстановленных страниц до клика.

Проверки кандидата приняты: [frontend43845528739](https://github.com/hipocrisle/nexusbro/actions/runs/43845528739) — success. Окончательный код приложения9801475 собран для обеих платформ в [43846415810](https://github.com/hipocrisle/nexusbro/actions/runs/43846415810): Linux build+frontend success; Windows build success, встроенный runtime-шаг остановился на недоработанной подготовке длинной формы тестом. Исправленный тест29ff718 повторно выполнен на **том же установщике** в [43849351553](https://github.com/hipocrisle/nexusbro/actions/runs/43849351553) — success, включая все сценарии VPN и прежние регрессии.

Тестовое окно после каждого перезапуска помещается в экран стенда; нижние кнопки достигаются Tab, затем нажимаются мышью. У Xray26.11.9 VLESS→freedom блокирует private IP по умолчанию, поэтому тестовый сервер явно разрешает только конкретный loopback-порт HTTP-фикстуры через finalRules. Это изменение только стенда, не настроек пользовательского VPN.
