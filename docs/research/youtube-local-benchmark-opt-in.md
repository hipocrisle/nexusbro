# Локальное сравнение YouTube в изолированном профиле

Прежний диагностический интерфейс проверял GITHUB_ACTIONS и поэтому отвергал
настоящий локальный эксперимент. Новый явный допуск не подменяет окружение CI.
На Linux он требует не-root владельца, канонический профиль внутри ~/AI,
права профиля 0700, отсутствие записи для других пользователей во всех
каталогах приватного дерева ниже AI (сам AI может быть групповым рабочим каталогом,
но не доступным для записи всем) и собственный обычный файл 0600
`.youtube-benchmark-opt-in` с точным содержимым версии протокола.
В обычных пользовательских профилях интерфейс остаётся закрыт.

Допуск относится только к существующим read-only reference/decode observations.
Проверки UI thread, tab, public video ID, document identity, advertised content,
CDP context и reservation остаются прежними. Произвольного JS интерфейса нет.
Тест использует собственный Xvfb, сохраняет sandbox и не открывает личный профиль.

`tests/gui/youtube_paired_home.py` вызывает тот же `arm` и общий валидатор,
что CI: light / normal / normal / light, 30 секунд прогрева и 90 секунд
измерений каждого плеча. Изменение качества, неизвестный decoder, неполный
учёт процессов, несовпадение участка видео, audio policy или отсутствие
нормального завершения делают сравнение непринятым. Включён watchdog плеча;
ошибка прекращает эксперимент и запускает штатную очистку.

Новая сборка обязательна: старый бинарник этот допуск не поддерживает.
До реального выполнения сравнения его результат не объявляется успешным.
Двухчасовой замер source1f успешно завершился, но для нового общего исходника
нужен отдельный полный замер, его результат не переносится автоматически.
