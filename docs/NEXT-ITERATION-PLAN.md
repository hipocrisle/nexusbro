# Исправления после пользовательской проверки 0.2.12

Дата: 17.11.2026. База: dev e2285d1. После просьбы только составить план пользователь поручил выполнить все исправления самостоятельно. Выпуск следующей версии — после завершения и проверок. Основной принцип: обычная браузерная работа как в Chrome; особенности NexusBro относятся к супер-вкладкам/сетевым профилям.

## Порядок и критерии

1. **Приватность и клавиатура.** В обычной Super плюс и Ctrl+T всегда создают обычную вкладку, независимо от активной. Справа от плюса стрелка с обычной/приватной вкладкой. В приватном окне/приватной Super нельзя создавать обычную вкладку незаметно: они всегда приватны. Индикатор приватности выровнять рядом с favicon, отдельно от крестика. В меню явно доступны новое окно и новое приватное окно. Сочетания работают в RU/EN, и в CEF-странице, и в оболочке, и в адресе/панелях. Проверить Ctrl+L/T/W/N/ShiftN/F/H/J/D/ShiftT, F5/F12; не ломать ввод текста и AltGr.
2. **Приватная Super сохраняет определение.** Постоянны ID, название и явно заданные настройки; данные просмотра временные. После перезапуска Super существует, но cookies/storage/cache/история/недавние/список загрузок и URL сессии отсутствуют. Не сохранять автоматически private start URL, адреса посещений или сетевые секреты в обычных метаданных. Явно заданная стартовая страница — настройка, не история. Скачанный файл на диске не удалять автоматически; объяснить это. Мигрировать текущие pvt-ID без переключения в обычный профиль. Учитывать аварийный выход, поздние callbacks и несколько окон одной Super.
3. **Перевод.** Текущая perevod.rs теряет все причины ошибок в Result<(),()>; один сбой отменяет остальные. Предыдущий native тест подменял Google локальной фикстурой — это не доказательство доступности живого сервиса. Сначала сохранить оригинал и корректное восстановление, затем диагностировать HTTP/timeout/TLS/429/parse через тот же прокси без прямого обхода. Ограничить запросы, пакетировать, retry временных ошибок, понятная ошибка и повтор. Проверить реальный сервис на живой странице; фикстура дополнительно проверяет 429/5xx/timeout/частичный перевод/отмену при навигации. Не логировать текст страницы и приватные URL.
4. **Единый интерфейс окон.** OknoBrowser.tsx сейчас урезан и привязан query super. Новое окно должно иметь полноценные навигацию, Super-панель/переключение/создание и одинаковые меню/кнопки. Общие компоненты вместо второго отдельного дизайна. Сессии ordinary по окнам независимы, normal профиль выбранной Super общий; private изолирован. Состояние активной Super хранить по окну; события адресовать только своему окну. Переключение не убивает CEF соседнего окна, close ACK до уничтожения HWND сохранить. ☰ в каждом окне открывает меню этого окна, а не пытается показать чужое main. Проверить второй EXE, CtrlN/ShiftN, скрытый main, закрытие окон в обоих порядках, несколько Super/масштаб/DPI.
5. **Chrome-подобная панель и меню.** Убрать постоянные кнопки истории/закладок/загрузок: доступны из общего меню и сочетаниями. Сеть и защита справа, маленькие одинаковые icon-only кнопки с tooltip/aria-label. Состояние сети: зелёный только по успешной проверке текущего маршрута; красный при подтверждённой недоступности; ожидание/неизвестно отдельно, не выдавать наличие CEF за доступность прокси. Не делать IP-запрос каждые2с: кэш/TTL/ограничение частоты, отмена старых проверок при смене узла. Проверять через выбранный выход, без direct fallback.
6. **DevTools resize.** Убрать input range. Перетаскиваемый разделитель между сайтом и DevTools, курсор col-resize, захват указателя и работа через native CEF HWND (HTML-полоску CEF может перекрыть). Min/max в пикселях с учётом DPI/изменения окна, ограничение частоты native resize, никаких зависаний/потери фокуса. Доступность с клавиатуры сохраняется. Проверить реальным drag на Windows, не только change DOM.
7. **Адресное меню.** Стандартное WebView меню несёт Emoji/пароли/направление/инструменты. Заменить только для адресного input на своё аккуратное: Undo/Redo, Cut/Copy/Paste/Delete/SelectAll; Paste-and-go по возможности. Пункты disabled по состоянию, выбранный фрагмент сохраняется, clipboard разрешения/ошибки, Esc/клик вне закрывают, нет мерцания CEF. Не перехватывать ПКМ на сайтах и других полях. Сохранить word/double-click/drag selection.
8. **Закладки.** Нынешняя звезда всегда ☆ и только save. Состояние для текущего URL, заполненная звезда после добавления; повторное нажатие удаляет (прямое требование). CtrlD и изменения из библиотеки синхронизируют все окна; показывать подтверждение, не оставлять ложное состояние при ошибке. Сохранить название/папку и разумные правила сравнения URL без потери query/fragment.
9. **Импорт из браузера.** Вместо HTML-only нужен мастер: обнаруженные браузеры и профили (Chrome/Edge/Brave/Chromium/Firefox по реально поддержанным), выбор источника, выбор данных, запуск задачи/прогресс/итог/отмена/ошибки/дубликаты. Основной обязательный объём — закладки с папками; не обещать пароли/cookies/историю без реализации. Читать source read-only/с копии, не закрывать чужой браузер и не изменять его файлы. Chromium Bookmarks JSON; Firefox places.sqlite через согласованный snapshot, не копировать только main при WAL. HTML оставить вторичным ручным вариантом. Проверить фикстуры nested folders/Unicode/duplicate/locked/missing; реальный Windows source fixture в стандартном каталоге. Никаких пользовательских профилей/секретов в public proof.
10. **Загрузки.** Компактные строки: имя, статус/размер, короткий домен; полный URL с чувствительными токенами не выводить. Меню строки: открыть/папка/retry при необходимости/удалить из списка; очистить завершённые/все записи. Удаление истории не удаляет файл; активную загрузку нельзя потерять молча (отмена отдельно). Установить почему PDF-письмо дало XML: браузер может действительно скачать MIME XML, не переименовывать его в PDF наугад. Проверить Content-Disposition, suggested name, content type и финальный path, несколько вложений и длинные signed URL. Не копировать присланную пользователем ссылку/токены в код, логи и отчёт.
11. **Контекстные меню вкладок.** Единые строки: подпись слева, shortcut справа, одинаковые высота/отступы/разделители. Исправить «Вернуть закрытую»; disabled если нечего вернуть, никогда не восстанавливать private. Меню у границ окна не обрезается. Общий renderer для меню стрелки, вкладки, приложения и адреса с разным составом действий.

## Проверка и выпуск

Сначала защита приватности и восстановимость данных, затем причина. Не запускать Rust-сборки на DE-1; только GitHub Actions. Лёгкие frontend/DOM проверки локально, один последовательный Xvfb CI-бинарник. Нужны реальные Windows mouse/keyboard RU+EN, drag разделителя, переключение Super в двух окнах, clipboard/address menu, bookmark toggle и импорт, download clear, persistent-private restart без приватных данных, реальный сервис перевода через прокси. Моки не заменяют живую проверку. CtrlF уже подтверждён пользователем — не регрессировать. Старые VLESS/recovery/lazy/close/ads тесты сохранить. Публикация после зелёного tagCI, Ed25519 пакетов и проверки publiclatest, версия согласованная во всех манифестах. Отчёт должен отличать наблюдаемое от гипотез и явно показывать непроверенное.
