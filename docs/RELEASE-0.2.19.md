# NexusBro 0.2.19 — кандидат: производительность

Приоритет выпуска — нагрузка при большом числе вкладок. Релиз ещё не опубликован.

- Косметическая фильтрация рекламы объединяет изменения страницы, избегает повторных обходов и обрабатывает элементы небольшими порциями. Обычный текст и формы не требуют чтения геометрии каждого элемента.
- Уведомления движка Windows обрабатываются по событию вместо постоянного опроса каждые 8 мс (интеграция и нативная приёмка ещё не завершены).

Нет доказанного процента улучшения общего CPU или памяти. Массовое изменение DOM проверено настоящим Chromium; полный Windows benchmark и нативная приёмка обязательны до публикации.

Компактное облако/подтверждённые статусы синхронизации и индивидуальные маршруты вкладок остаются отдельными незавершёнными изменениями и в этот кандидат пока не включены.
