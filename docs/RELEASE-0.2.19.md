# NexusBro 0.2.19

- Компактные заголовки «Облако» и «На устройстве». Дата и подробности синхронизации перенесены в подсказку.
- Облачко зелёное после подтверждённой синхронизации текущего определения Super; ошибки и конфликты — красные, отключённая синхронизация — серая.
- Отключённые Super, включая сохранённые закрытые, остаются видимыми в группе «На устройстве». Данные при отключении не удаляются.
- Состояние подтверждения и ошибки сохраняется после перезапуска. Старая дата успешного обмена не выдаётся за подтверждение новых изменений.

Для данных, синхронизированных старой версией без подтверждений по отдельным Super, первый обмен устанавливает подтверждённое состояние.
