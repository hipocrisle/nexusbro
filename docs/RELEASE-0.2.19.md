# NexusBro 0.2.19 — кандидат: производительность

Релиз ещё не опубликован. Продуктовая приёмка и сравнительный замер CPU продолжаются.

- Исправлена передача видимости встроенным окнам Chromium: неактивные вкладки и страницы скрытых супервкладок должны переходить в фон; при сворачивании всего окна должны останавливаться фоновые кадровые callbacks.
- Windows обрабатывает команды движка по событиям вместо постоянного опроса каждые 8 мс. Служебное обслуживание остаётся ограниченным; нулевой idle CPU не обещается.
- Косметический фильтр рекламы объединяет изменения страницы, обрабатывает их небольшими порциями и избегает чтения размеров каждого обычного элемента.
- Исправлено восстановление клавиатурного фокуса после закрытия активной вкладки.
- Из текущей dev-базы также включены общая разблокировка хранилища на сессию браузера, трёхбуквенные имена в свёрнутой панели, предупреждения синхронизации вместо обычных значков и сохранение подписей обычных вкладок при уплотнении.

Автоматическая выгрузка посещённых страниц и объединение движков супервкладок пока не реализованы; уменьшение постоянного расхода памяти не заявляется. Компактное облако с подтверждёнными статусами и индивидуальные маршруты вкладок остаются отдельными изменениями.
