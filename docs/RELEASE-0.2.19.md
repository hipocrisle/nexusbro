# NexusBro 0.2.19 — производительность Windows

Исправлена передача видимости страницам встроенного Chromium. Неактивные вкладки и страницы скрытых супервкладок переходят в фон; при сворачивании окна фоновые кадровые callbacks останавливаются.

В сравнении с 0.2.18 на одной Windows-машине (8 супервкладок, 1000 сохранённых /24 посещённых страницы) CPU: свёрнутое окно **9,94% → 2,95%**, после возврата **9,97% → 2,39%**. Это контролируемый сценарий с тестовыми страницами; результат на конкретных сайтах зависит от их нагрузки.

Также:

- Команды Windows-движка пробуждают его по событию вместо опроса каждые 8 мс.
- Косметический фильтр рекламы объединяет изменения DOM и обрабатывает их небольшими порциями.
- Восстановлен фокус после закрытия активной вкладки и работа Ctrl+Shift+T.
- Разблокировка хранилища действует на сессию браузера; стартовый мастер-пароль и Ctrl+Shift+L сохранены.
- В свёрнутой панели — трёхбуквенные имена и предупреждения синхронизации; подписи обычных вкладок сохраняются при уплотнении.

Проверено: Windows59/Linux41 нативных checkpoints, отдельная проверка скрытых страниц/изображения/физического ввода и 72 проверенных интервала большого сценария.

Автоматической выгрузки посещённых страниц для экономии памяти пока нет; основная стоимость отдельных движков супервкладок сохраняется. Индивидуальные маршруты вкладок и расширенное оформление облака остаются отдельными изменениями.
