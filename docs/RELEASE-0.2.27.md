# NexusBro 0.2.27


- Автоматическое освобождение ресурсов целой неактивной супервкладки с восстановлением по клику. Медиа, звонки, загрузки и несохранённые данные защищены.
- Подготовлен лёгкий плеер для отдельных публичных видео YouTube: качество, субтитры, перемотка, громкость, полноэкранный режим и фоновое воспроизведение.
- Подготовлены скачивание видео и аудио, отмена и защита от перезаписи файла. Позиция просмотра сохраняется отдельно для профилей супервкладок и путей.
- Добавлены поддержка SponsorBlock и Return YouTube Dislike и понятные статусы недоступности внешних сервисов.
- Лёгкий режим использует выбранный путь вкладки. Google cookies не переносятся; при ограничении анонимного доступа доступен обычный YouTube.
- Загрузки файлов показывают состояние, объём, процент и скорость; добавлены «Открыть файл» и «Показать в папке». При неизвестном размере отображается процесс без ложного процента.
- При скачивании обновления сайты остаются видны. Перед установкой приложение дожидается безопасного завершения движков.
- Исправлено перехватывание клика системной подсказкой у кнопки пути на Linux. Штатное закрытие и перезапуск сохраняют открытые окна.

Не заявляется ускорение или снижение памяти «в три раза»: публичный парный замер ещё не выполнен.

- «Путь вкладки» и проверка сетевого выхода объединены в «Сеть вкладки»: подключение, фактический IP и страна в одном окне. При недоступном подключении прямой обход не включается.
- Ctrl+S и «Сохранить страницу…» сохраняют страницу в MHTML для последующего открытия без сети.

Функциональная проверка лёгкого YouTube на кандидате: 120 секунд видео 720p с выбранным по умолчанию VP9, без пропущенных кадров; пять остановок буферизации восстановились автоматически. Непрерывное воспроизведение и преимущество по ресурсам этим результатом не утверждаются.
