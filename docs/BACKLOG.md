## Следующий общий релиз: ресурсы и лёгкий YouTube — решение владельца 24.11.2026

Уточнение владельца: «публикуй только сразу с Лёгкий режим YouTube». Следующий публичный релиз обязан включать и ресурсные изменения, и первый пакет лёгкого YouTube ниже. Промежуточный релиз только с засыпанием Super запрещён. Это условие публикации, а не заявление о готовности функций. Финальная объединённая сборка должна пройти нативную и ресурсную приёмку до публикации.

Первый пакет:

1. Встроенный лёгкий плеер по действию «Открыть в лёгком режиме» с сохранением доступа к обычному youtube.com. Рассмотреть libmpv и получение потоков через поддерживаемые инструменты; собственный тяжёлый сайт внутри плеера не загружать.
2. SponsorBlock для пропуска интеграций; Return YouTube Dislike для отображения доступных оценок.
3. Скачивание видео/аудио через yt-dlp, при необходимости FFmpeg, с прогрессом и понятными ошибками.
4. Качество, субтитры, продолжение просмотра и непрерывное воспроизведение при переключении вкладки/сворачивании; действующая защита медиа от автоматического сна обязательна.
5. Строго соблюдать эффективный путь конкретной вкладки и изоляцию профиля Super+путь. Получение потока, воспроизведение, превью, сторонние API и скачивание проходят через этот путь; недоступный маршрут не заменять Direct. Google cookies/учётные данные не копировать между профилями и не отдавать внешним утилитам по умолчанию.
6. Реальное испытание на Windows/Linux: воспроизведение, маршруты и отказ подключения, фон, скачивание, обновление вспомогательных компонентов. Парный замер обычного YouTube и лёгкого режима на одной машине, одинаковом видео/качестве/аппаратном декодировании, с учётом ВСЕХ процессов и буферов. Не обещать рекламные «в три раза» или «один процесс» без собственного измерения.

Следующее расширение отдельно: собственная лента, подписки и комментарии; аккаунтная интеграция требует отдельного решения о безопасном входе. Перед реализацией зафиксировать контракты, границы модулей и проверить лицензии всех включаемых компонентов.

Источники для архитектурного аудита (проверены исходники, приложение не запускалось): [Stream Tube](https://github.com/Avaneesh-Inamdar/Stream-Tube-Desktop), [player](https://github.com/Avaneesh-Inamdar/Stream-Tube-Desktop/tree/main/src/player), [stream extraction](https://github.com/Avaneesh-Inamdar/Stream-Tube-Desktop/blob/main/src/api/streams.rs), [SponsorBlock/RYD](https://github.com/Avaneesh-Inamdar/Stream-Tube-Desktop/blob/main/src/api/services.rs). Это специализированный клиент Rust/GPUI + libmpv, а не переписанный YouTube; авторские цифры README — около405МБ на главной/565МБ при воспроизведении против1203МБ Edge в его условиях, не результат NexusBro.
