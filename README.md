# NexusBro

Браузер с **супер-вкладками**: отдельный профиль, свои входы на сайты,
подключение через прокси или VPN. Внутри — привычные обычные вкладки.

[Скачать последнюю версию для Windows или Linux](https://github.com/hipocrisle/nexusbro/releases/latest).

Работают восстановление сессий, сохранённые супер-вкладки, перетаскивание,
закрепление через меню, фавиконки, инструменты разработчика F12 и исходный код
в отдельной вкладке. Есть темы, шрифты, настройки поиска и масштаба.

Поддерживаются SOCKS5 и HTTP-прокси, VLESS-ссылки, подписки со списками ссылок
и полными Xray JSON-конфигурациями. Настройки подключения задаются отдельно
для каждого профиля. Доменная блокировка рекламы и отслеживания сопровождается
отчётом по сервисам, правилам и событиям.

Оболочка — Tauri и React; страницы — встроенный CEF. Движок и Xray входят в
установочные пакеты. Поддерживаются Windows и Linux; macOS пока не поддерживается.

## Разработка

Инструкции по CEF и устройству вкладок: [CEF-TABS.md](docs/CEF-TABS.md).
Сборке нужны Node.js, Rust, системные зависимости Tauri и дистрибутив CEF,
соответствующий версии crate `cef`. CI скачивает и проверяет зависимости,
собирает пакеты и выполняет экранную приёмку на Windows.

Изменения: [0.2.8](docs/RELEASE-0.2.8.md).
