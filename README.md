# NexusBro

Браузер с **супер-вкладками**: каждая вкладка верхнего уровня — отдельный
браузер со своим профилем и своим выходом в сеть. Внутри неё открывайте
сколько угодно обычных вкладок — весь сайт со всеми его адресами пойдёт
через выбранный выход.

Зачем так: правила «этот домен — через этот прокси» не работают. Один
YouTube тянет десятки разных адресов, и перечислять их пришлось бы для
каждого сервиса. Супер-вкладка решает это целиком.

## Состояние

Ранняя разработка. Работает: создание супер-вкладок, свой профиль и свой
прокси на вкладку, встраивание движка в окно, память между запусками.

## Как устроено

Оболочка поверх готового [ungoogled-chromium](https://github.com/ungoogled-software/ungoogled-chromium)
— движка со срезанной слежкой. Свой движок не собираем: это десятки часов
на машину сборки и пересборка каждый месяц.

* **Windows** — движок лежит внутри программы, ставить ничего не нужно.
* **Linux** — берётся системный `ungoogled-chromium` или `chromium`.
* **macOS** — пока нет: свежих сборок ungoogled-chromium под мак нет
  с ноября 2024 года, а отдавать людям браузер двухлетней давности нельзя.
